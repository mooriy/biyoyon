# びよよ～ん

スマホでふったり、ボタンでのばしたりして遊べるウェブアプリです。

公開ページ: https://mooriy.github.io/biyoyon/

`index.html` をブラウザで開くと、ボタンやタップで発射でき、丸い先端をドラッグして遊べます。「画面いっぱいであそぶ」を押すと、びよよ～んを大きく表示できます。右上の × で元に戻ります。
ブラウザの操作バーは、端末やブラウザによって表示されたままになることがあります。

スマホの動きに反応させるには、ファイル一式を HTTPS で配信し、スマホで開いて「スマホをふってあそぶ」を押してください。権限の確認が表示された場合は許可してください。画面いっぱいで遊ぶときは、先にこの操作をしてください。

動きセンサーが利用できない環境でも、ボタンとドラッグで遊べます。
